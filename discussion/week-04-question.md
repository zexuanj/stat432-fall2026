Suppose a researcher fits a lasso model and compares several penalty values \(\lambda\). Instead of choosing \(\lambda\) using cross-validation on the training data, the researcher calculates the test MSE for each candidate \(\lambda\) and chooses the one with the smallest test MSE. Why is this procedure problematic, even though the final model was never directly fitted on the test observations? Explain what information from the test set has leaked into the modeling process and how the penalty should be chosen correctly.
